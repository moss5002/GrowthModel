# Echo — Groupe 6

Projet du cours Growth Modeling & Data-Driven Strategy.

## Question

Faut-il généraliser les notifications agressives chez Echo ?

Echo est une application de podcasts gratuite financée par la publicité.
Les données couvrent janvier 2025 à juin 2026.

## Livrables

À remettre le 9 novembre 2026 à 18 h :

- Un modèle de croissance avec un backtest sur 2025 et trois scénarios.
- Un rapport d'environ quatre pages avec une recommandation, un plan A/B et le journal de nettoyage.
- Environ dix slides pour une soutenance de huit minutes le 10 novembre, suivie d'une question traitée avec le modèle.

Les fichiers remis portent le préfixe `G06_Echo_`.

## Fichiers

- `data/` : les trois CSV bruts, à conserver sans modification.
- `Notebook.ipynb` : notebook Python du projet, à compléter.
- [Data pack Echo](docs/Echo%20-%20Project%20data%20pack.pdf) : contexte et description des données.
- [Cours](docs/Growth%20modeling%20class.pdf).
- [Simulateur du cours](docs/IMT%20-%20Growth%20Model%20Simulator.xlsx) : exemple pédagogique.

## Travailler sur le projet

1. Récupérer les derniers changements avec `git pull --ff-only`.
2. Ouvrir `Notebook.ipynb` dans Jupyter ou VS Code avec un noyau Python 3.
3. Exécuter le notebook depuis la racine du dépôt pour accéder à `data/`.
4. Documenter les décisions de nettoyage et les hypothèses au fil du travail.
5. Vérifier les changements, puis faire un commit et un push à la fin de chaque étape.

Se coordonner avant de modifier le même notebook à plusieurs.
